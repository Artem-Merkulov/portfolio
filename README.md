# Portfolio

Личные и учебные проекты по Data Engineering и анализу данных.

Здесь два раздела: **DE** — инженерия данных (ETL, DWH, оркестрация, потоковая обработка), **DA** — аналитика данных (исследовательский анализ, A/B-тесты, метрики продукта).

```
portfolio
├── DE  — проекты по Data Engineering
└── DA  — проекты по Data Analysis
```

Подробные описания — в `README.md` внутри каждой директории.

| [Поиск сообществ с высокой конверсией в первое сообщение](DE/Поиск%20сообществ%20с%20высокой%20конверсией%20в%20первое%20сообщение) | Перенос данных из транзакционной PostgreSQL в аналитическую Vertica |

## Структура

- **[DE](DE/)** — ETL-пайплайны, хранилища данных, микросервисы, потоковая обработка. Стек: Python, SQL, Spark, Kafka, Airflow, Docker, Kubernetes, PostgreSQL, Vertica, Hadoop.
- **[DA](DA/)** — 12 ноутбуков с исследовательским анализом, A/B-тестами и продуктовыми метриками. Стек: Python, pandas, numpy, scipy, seaborn, plotly, SQL.
