# Flask Project

Микросервисное приложение, состоящее из трёх сервисов:

```
Adminer    - клиент для подключения к различным СУБД
PostgreSQL - реляционная СУБД для хранения данных сайта
Flask      - образец стартовой страницы сайта
```

Приложение построено при помощи Docker и docker-compose.

## Запуск

1. Скопировать переменные окружения:

   ```bash
   cp .env.example .env
   ```

2. Заполнить `.env` своими значениями. Файл `.env` в репозиторий не попадает — он в `.gitignore`.

3. Поднять стек:

   ```bash
   docker compose up -d
   ```

4. Открыть:
   - сайт — http://127.0.0.1:8008
   - Adminer — http://127.0.0.1:8080
