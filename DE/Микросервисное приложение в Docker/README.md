# Flask Project

Микросервисное приложение, состоящее из трёх сервисов:
```
Adminer - клиент для подключения к различным СУБД
PostgreSQL - реляционная СУБД для хранения данных сайта
Стартовая страница сайта на Flask - образец стартовой страницы сайта
```

Приложение построено при помощи docker и docker-compose.

Проект сделан по [курсу Сергея Балакирева по Flask и Docker](https://stepik.org/a/183363)
